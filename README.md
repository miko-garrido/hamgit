Made for fun, also annoyance. Four conditions when I made this:

1. Wanted to try Tauri
2. Wish I had just the source control from VSCode, nothing else
3. I dislike typing git status/switch/pull repeatedly
4. Just watched Hamnet and Paul Mescal

So Hamgit.

This is not a whole git UI. It’s a repo branch switcher I made literally just for me.

Here's everything it can't do:

1. No commit (lol)
2. No pull request
3. No merge
4. No diffs
5. No staging
6. No cherry-picking
7. No rebasing
8. No blame

If I want any of the above, I go to Github, Linear, Cursor, or wherever I already build. If I'm being honest, I usually ask Codex to “take me back to main”.

Hamgit is just a way to keep agents from running into each other and make switching back and forth between sessions easier because I like to juggle multi-repo projects and workspaces.

I switched this github to public so I can keep Tauri releases simple.
